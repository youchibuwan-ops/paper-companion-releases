## 安装和开始

下载附件 **PaperCompanion-Setup.exe**，双击安装。GitHub 自动生成的 Source code 压缩包只包含本仓库的发布资料。程序默认安装到 D 盘，可选择其他空目录或已登记的程序目录。安装前请关闭论文伴读窗口。安装包尚未数字签名，Windows 可能显示相应提示。

1. 打开软件，选择「论文阅读」，打开本机 PDF。
2. 选择 AI 服务。Codex 与 DSH 需要先在本机安装并配置可用账户；DeepSeek、Claude、Qwen API 使用各自的密钥和模型。
3. 选中原文后提问、写批注、翻译或查资料。问答可从对应原文或「讨论记录」找回。
4. Codex 或 DSH 可指定本机项目目录，也可留空使用本篇论文的独立持续会话。可勾选首次附上整篇原文，或主动发送整篇原文。
5. 选错范围可点击「取消选区」或按 Esc；同一文件重开时恢复阅读位置与缩放。

## 会话与数据

Codex 和 DSH 分别保存本篇论文的原生会话，切换选区后继续使用对应会话。首次发送完整可提取原文后，后续追问不重复附送；工具确认已接收问题后，即使回答中断，也保留全文已送达状态。原文参考保存在应用数据中，供原生会话按需只读核对。普通直连 API 不提供这一原生持续全文模式。

所选原文、问题和图片会发送至所选 AI 服务；启用全文时发送整篇可提取文字。AI 提炼关键词会发送选区内容和论文文件名，搜索词会发送到公开检索服务。服务商处理历史、缓存或工具请求仍可能计费。DSH 会话日志由原生配置控制，已核验版本默认启用日志提交。

原文件留在原位置，只读打开；批注、想法、讨论和译文独立保存在本机，设置中可查看数据目录。相同文字在不同位置仍分别关联。文件版本按路径、大小和修改时间识别；内容变化但大小及修改时间均未变时，可能无法识别。

## 阅读、翻译与写作

- 本机英译中首次下载约 114 MiB 模型；安装后翻译不向网络发送原文。支持选区、本页与全文翻译，译文可编辑保存。
- 支持论文写作、自由写作、公式编辑及 Word 导出。AI 讨论不会自动覆盖用户正文。
- 普通阅读支持多种文本格式，部分格式依赖额外工具。扫描页可看原图，没有文字层时无法直接选字。
- AI 解释、翻译及检索摘要需结合原文核对；摘要与书目不代表全文授权。全文缺失或超过 500000 字符时明确报错，不自动截断。

## 许可与素材来源

设置 →「关于与许可」提供随包离线材料，翻译栏也可查看模型来源。仓库保留 [第三方通知](THIRD-PARTY-NOTICES.txt)、[运行依赖清单](THIRD-PARTY-PACKAGES.json)及[版本与来源](sources.json)。
