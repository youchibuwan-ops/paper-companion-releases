## 安装和开始

下载附件 **PaperCompanion-Setup.exe**，双击安装。GitHub 自动生成的 Source code 压缩包只包含本仓库的发布资料。程序默认安装到 D 盘，可选择其他空目录或已登记的程序目录。安装前请关闭论文伴读窗口。安装包尚未数字签名，Windows 可能显示相应提示。

1. 打开软件，选择「论文阅读」，打开本机 PDF。
2. 选择 AI 服务。Codex、Claude Code 与 DSH 需要先在本机安装并配置可用账户；DeepSeek、Claude、Qwen API 使用各自的密钥和模型。
3. 选中原文后提问、写批注、翻译或查资料。问答可从对应原文或「讨论记录」找回。
4. Codex、Claude Code 或 DSH 可指定本机项目目录，也可留空使用本篇论文的独立持续会话。可主动开始整篇图文初读，并在同一会话继续追问。
5. 选错范围可点击「取消选区」或按 Esc；同一文件重开时恢复阅读位置与缩放。

## 会话与数据

Codex、Claude Code 与 DSH 分别保留原生会话；首次提供原 PDF 或全部原版页图后，继续追问沿用已保存会话。切换选区不新建会话，旧对话可选回。DSH 模型按原有通道分组，使用已有配置与凭据。

API 直连会保存本地讨论，但不等于服务商保存了全文背景。后续请求需携带原 PDF/页图与历史，仍可能计费。Claude API、已接入的百炼 PDF 模型走 PDF 文档输入；DeepSeek Flash 与已接入的百炼视觉模型走完整页图。平台、模型和地域限制会明确提示，不会自动换模型或退回文字摘要。图文输入不保证 AI 理解正确，须结合原文核对。

正文、问题、图片或明确开启的全文图文会发送至所选服务；密钥与个人阅读数据不包含在安装包中。第三方原生程序的日志与数据处理受其自身配置约束。具体支持范围与验证边界见 [版本说明](RELEASE-NOTES.md)。

原文件留在原位置，只读打开；批注、想法、讨论和译文独立保存在本机，设置中可查看数据目录。相同文字在不同位置仍分别关联。文件版本按路径、大小和修改时间识别；内容变化但大小及修改时间均未变时，可能无法识别。

## 阅读、翻译与写作

- 本机英译中首次下载约 114 MiB 模型；安装后翻译不向网络发送原文。支持选区、本页与全文翻译，译文可编辑保存。
- 支持论文写作、自由写作、公式编辑及 Word 导出。AI 讨论不会自动覆盖用户正文。
- 普通阅读支持多种文本格式，部分格式依赖额外工具。扫描页可看原图，没有文字层时无法直接选字。
- AI 解释、翻译及检索摘要需结合原文核对；摘要与书目不代表全文授权。原文件读取失败或超过所选服务的页数、容量或上下文限制时明确报错，不自动截断。
