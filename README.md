## 下载与安装

在上面的下载页面选择附件 `PaperCompanion-Setup.exe`，双击安装。无需下载 GitHub 自动生成的 Source code 压缩包，它们只包含本仓库的发布资料。安装时可以选择程序目录。安装包目前没有数字签名，Windows 可能显示相关提示。

## 开始使用

1. 打开软件，选择「论文阅读」，打开本机 PDF。
2. 在右侧选择 AI 服务。使用 Codex 或 DeepSeek Harness（DSH）时，先在本机安装对应工具并配置账号；也可以配置 DeepSeek、Claude、Qwen 的 API 密钥，或打开官网对话。
3. 使用原生会话时，可在「本篇论文持续会话」中选择该工具使用的本机项目目录，也可以留空，再发送整篇原文；使用官网时，可填写 ChatGPT 项目主页链接或 DeepSeek 已有对话链接。新手引导会介绍这两种入口。
4. 选中论文中需要理解的文字，输入问题；也可以添加自己的批注。Codex 与 DSH 分别保存本篇论文的原生会话，切换选区后继续使用对应会话。
5. 选错范围时点击「取消选区」或在正文按 Esc；保存过的问答可以在右侧「讨论记录」中查看。
6. 在设置中调整 PDF 默认缩放；重新打开同一文件时会恢复该论文上次的阅读位置与缩放。
7. 选择原文后点击「查资料」，可手动输入关键词，也可以使用「AI 提炼关键词」后再搜索。

## 项目与全文如何继续使用

Codex 和 DSH 使用各自的原生持续会话；同一篇论文在不同选区中的追问会沿用相应会话。选择的本机项目目录供该工具读取相关材料，两种工具的项目与会话设置分别保存。启用全文后，软件在该会话首次需要时附上完整可提取文字，后续不再重复附送。原生工具确认已接收问题后，即使回答失败，也会保留全文已送达状态，避免重试时再次发送全文。软件还会保留一份本机全文参考，供原生会话在需要核对时只读查阅。

ChatGPT 官网入口可以从项目主页开始新对话；DeepSeek 官网入口支持已有对话链接。官网对话仍按选区关联，已有关联的讨论继续使用原对话。普通 DeepSeek、Claude、Qwen 直连 API 暂不提供本软件的持续项目全文模式，界面会明确提示。

软件本身免费。AI 服务需用户自行配置，API 或原生工具调用可能由服务商另行收费；原生会话继续处理历史或缓存也可能计费，不能将“不重复附送全文”理解为后续上下文免费，也不能将网页免费额度视为 API 额度。所选论文文字和问题会发送给所选的 AI 服务；启用全文时会发送整篇可提取原文。AI 提炼关键词会发送选中的原文（最多前 12000 字）和论文文件名，也会消耗相应额度；图片提问还会发送选中的图片。搜索时关键词会发送到公开检索服务。请根据论文内容选择是否使用。

## 其他功能与限制

- 支持本机英译中；首次使用需下载翻译模型，专业术语和含义需要对照原文检查。
- 支持论文写作和导出 Word。普通阅读还支持多种文本格式，部分格式需要额外工具。
- 扫描版 PDF 没有可提取文字时无法直接选中文字。AI 的解释和翻译可能出错，请核对原文。
- 全文需先完成页面文字提取；超过 500000 字符时会明确报错，不自动截断。原生工具和官网仍有各自的上下文、账号与服务限制。
- 文件位置、批注和本机 AI 讨论保存在本机；DeepSeek 和 ChatGPT 网页对话支持将回答保存到本机；未成功保存的回答仍需在相应官网查看。原始文件不会被写入或覆盖。
- 程序通过路径、大小和修改时间识别文件版本；如果文件内容发生变化但大小和修改时间都未变，可能无法识别。
- DSH 接入已用本机安装的 0.2.1-rc.2 验证初始化和模型目录读取，该检查未生成回答；原生会话与网页保存流程另用隔离模拟服务验证。真实官网账号登录、当前页面结构及远端 AI 回答质量未包含在本轮验证范围。
